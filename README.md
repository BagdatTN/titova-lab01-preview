# Laboratory 01 review preview

Russian methodical guide and interactive synthetic micrograph exercise for review.
Open `index.html`, then follow the link to the micrograph viewer. Both pages embed
their assets and work without a build step. Student records and conclusions are on paper.

The micrographs M01/M02 are generated teaching imitations with an assigned scale;
they are not images of real specimens. The guide is a draft for teacher review.
Illustrations in the theory are attributed to Yu. V. Titova's 2014 laboratory manual.
External references retain their authors' rights; no blanket license is granted.

This repository contains the shareable preview only. Working sources, project
documents, reference PDFs and historical drafts are maintained separately.
